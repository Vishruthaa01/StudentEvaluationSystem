<h3>Tech Stack and Tools:</h3>
<h4>Language:</h4> Java (compiled to bytecode, featuring console application logic)  
<h4>Database:</h4> MySQL (kec_db schema managing students, courses, enrollments, and assessment marks)     
<h4>Database Connectivity / Driver:</h4> JDBC (java.sql, DriverManager, and DBConnection configured with MySQL Connector)    

<h4>Java Development Kit (JDK):</h4> Used to compile and execute the core Java source files (MainApp.java, AcademicDAO.java, and DBConnection.java) and manage compiled bytecode (.class files).  
<h4>MySQL Server:</h4> The relational database management system used to host and manage the kec_db database.  
<h4>JDBC (Java Database Connectivity) API:</h4> The Java API (java.sql, DriverManager) used to establish secure database connections and execute queries between the application and MySQL.
<h4>Code Editor:</h4> Visual Studio Code use for development environment.

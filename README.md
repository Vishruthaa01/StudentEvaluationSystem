Tech Stack and Tools:
Language: Java (compiled to bytecode, featuring console application logic)
Database: MySQL (kec_db schema managing students, courses, enrollments, and assessment marks)   
Database Connectivity / Driver: JDBC (java.sql, DriverManager, and DBConnection configured with MySQL Connector)  

Java Development Kit (JDK) / Java Runtime: Used to compile and execute the core Java source files (MainApp.java, AcademicDAO.java, and DBConnection.java) and manage compiled bytecode (.class files).  
MySQL Server: The relational database management system used to host and manage the kec_db database.  
JDBC (Java Database Connectivity) API: The Java API (java.sql, DriverManager) used to establish secure database connections and execute queries between the application and MySQL.
Code Editor: Visual Studio Code use for development environment.
